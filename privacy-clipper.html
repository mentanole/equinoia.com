Equinoia Clipper privacy policy

Last updated: 2026-10-07

Equinoia Clipper ("the extension") is a browser extension and a companion to the Equinoia desktop application. It lets you save an image or video you see on a web page to your own Equinoia library on your computer.

1. What the extension does with data

When you choose "Save to Equinoia", "Save linked file to Equinoia" or "Save page link to Equinoia", or click the extension icon, the extension:

  • downloads the file you right-clicked, using your browser, the same way the page itself loads it (the website receives an ordinary request from your browser, including its usual cookies);
  • sends that file, the address and the title of the page to the Equinoia application running on the same computer, at http://127.0.0.1:8000.

Nothing else is read, and nothing happens until you use one of these commands.

2. What the extension does not do

  • It does not send any data to the developer or to any third party. The address 127.0.0.1 is your own computer; the data never leaves it through the extension.
  • It does not collect browsing history, personal information, analytics or usage statistics.
  • It does not store data itself; files are kept by the Equinoia application in the library folder you chose.
  • It does not load or run code from the internet.

3. Your control

Files saved to Equinoia stay on your computer. You can delete them in the application at any time. Removing the extension stops all of the above. For the desktop application itself, see the Equinoia privacy policy.
